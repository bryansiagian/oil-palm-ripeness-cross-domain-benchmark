# Oil Palm Ripeness Cross-Domain Benchmark

A cross-domain object detection benchmark for oil palm fresh fruit bunch (FFB) ripeness detection using RF-DETR, YOLO11, and YOLOv8.

## Project Objectives

1. Harmonize class taxonomies across three public oil palm datasets.
2. Evaluate cross-domain generalization between palm oil mills and plantations, including Indonesia and Malaysia.
3. Compare RF-DETR, YOLO11, and YOLOv8 in terms of detection accuracy and inference speed.

## Datasets

- South Kalimantan palm oil mill dataset — Scientific Data (2023).
- Central Kalimantan plantation dataset — Scientific Data (2025).
- Malaysia outdoor oil palm dataset — Data in Brief (2024).

## Evaluation Metrics

- mAP@50
- mAP@50:95
- Cross-domain mAP degradation
- Inference FPS
